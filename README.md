# SaleAnalytic# 📊 Sales Performance Analysis Dashboard

## 📌 Giới thiệu
Dự án phân tích dữ liệu bán hàng giai đoạn **2012 – 2015** bằng **Power BI**.  
Mục tiêu là đánh giá hiệu suất bán hàng theo **sản phẩm, khách hàng và vận chuyển**, từ đó hỗ trợ ra quyết định kinh doanh và marketing.

---

## 🛠️ Công cụ sử dụng
- Power BI Service
- Excel (dữ liệu nguồn)
- DAX (Data Analysis Expressions)
- Data Visualization & Dashboard Design

---

## 📂 Nội dung Repo
- `sales_dashboard.pdf` : Dashboard xuất từ Power BI  
- `dataset.xlsx` : Dữ liệu bán hàng gốc (2012–2015)  
- `/images` : Hình ảnh chụp màn hình dashboard  
- `README.md` : Mô tả dự án  

---

## 🚀 Các bước thực hiện
1. Thu thập dữ liệu bán hàng (2012–2015).  
2. Làm sạch dữ liệu, chuẩn hóa định dạng và xây dựng mô hình dữ liệu trong Power BI.  
3. Thiết kế dashboard trực quan với 4 trang:  
   - **Intro** – Tổng quan dữ liệu  
   - **Product** – Phân tích theo sản phẩm & lợi nhuận  
   - **Customer** – Phân tích hành vi khách hàng  
   - **Shipping** – Phân tích chi phí và hiệu quả vận chuyển  

---

## 📊 Kết quả nổi bật
- Xác định **Top 5** và **Bottom 5** sản phẩm theo biên lợi nhuận.  
- Phân tích **doanh thu và lợi nhuận** chi tiết theo từng sản phẩm, danh mục.  
- Biểu đồ động thể hiện xu hướng doanh thu, lợi nhuận theo quý (2012–2015).  
- Phân khúc khách hàng theo **giá trị (Value)** và **tần suất mua hàng (Frequency)** để hỗ trợ chiến lược marketing.  
- Đánh giá hiệu quả vận chuyển theo chi phí & thời gian.
